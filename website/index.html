Which Minecraft version does Stella support?

Minecraft Java 1.21.11 with Fabric Loader 0.17.3 or newer and Fabric API. Put the Stella jar in your mods folder; don't combine it with another build of Stella.

Can I use Stella on any server?

Check each server's rules first. Some servers don't allow ESP, freecam or base-finding tools, and breaking a server's rules can get you banned there. You're responsible for how you use Stella.

How do I open the ClickGUI?

Press Right Shift in game. You can change the key in the ClickGUI module, switch between the window and dropdown views with the button at the bottom, and drag the HUD anywhere from the HUD editor.

Is it safe to install?

Every release passes an automated in-game test and a malware audit (ClamAV plus a scan of the compiled code for network and process calls) before it's published, and comes with a SHA-256 hash you can check.
